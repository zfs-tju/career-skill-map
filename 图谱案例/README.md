## 📖 项目简介

WorkWill 通过**多智能体流水线**将各类权威文档（职业标准、高校培养方案、政策与行业报告、竞赛通知）中的就业信息自动抽取入图，构建覆盖**专业岗位、技能结构、课程体系、竞赛实践**四大维度的就业知识图谱，并在此之上为在校大学生提供**"个性培养"与"职业方向"两大智能报告**、跨维度检索与页号级溯源、个人技能画像等服务。

- **双源融合**：权威数据层（文档抽取）+ 大模型通用知识，以分层接地规则缓解幻觉
- **全程合规**：仅调用天津大学校内词元服务（ai.tju.edu.cn），遵守平台限速（60 次/分、3000 次/时），无外部大模型依赖

**目标用户**：在校大学生（低年级探索方向、高年级准备路径）、辅导员与就业指导教师。

### 校园应用价值

- **对学生**：低年级用"个性培养报告"规划四年选课与竞赛节奏，高年级用"职业方向报告"定位毕业出路（就业/考研/保研/选调），个人画像随学习进度持续点亮，让职业规划从"纸上谈兵"变成"按图推进"。
- **对教师**：辅导员与就业指导教师无需逐份翻阅培养方案与职业标准，借助图谱检索与智能报告即可给出有出处的个性化指导，指导效率与专业性同步提升。
- **对学校**：培养方案 Excel 直转入图，"课程体系 ↔ 岗位技能"的对接情况可视化，为培养方案修订与就业工作提供数据依据。
- **知识资产沉淀**：多工作区材料可共享至公共资料库，全局图谱自动合并去重，逐步形成校本级就业知识库，年级与专业越用越准。

## 🆚 解决什么问题

| 痛点 | WorkWill 的方案 |
| --- | --- |
| 大模型读长文档能力弱 | 文档分段（单段上限 30000 字符）+ 文档类型感知抽取模板 + 严格六表契约输出 |
| 大模型幻觉、编造实体 | 权威数据层优先；事实条目强制标注 `[来源：数据来源名 页号]`；AI 建议与事实分层不得混排 |
| 就业信息散落在几十份文档里 | 四大维度图谱统一建模，跨维度检索与页号级溯源 |
| 培养方案 Excel 与图谱格式不兼容 | Excel 直传通道自动识别培养方案工作簿，转换为标准六表后入图 |
| 规划建议空泛、不可执行 | 课程按"开课学年/开课学期"逐字归位；路径建议全部落到图谱中真实节点 |

## ✨ 功能特性

- 🗂️ **四通道材料导入** —— 网页 URL 抓取 / 粘贴文本 / 图片本地 OCR / 培养方案 Excel 直传
- 🕸️ **四大图谱维度** —— 专业岗位、技能结构、课程体系、竞赛实践，支持可视化增删改与多工作区管理
- 🖱️ **图谱交互探索** —— 默认"四大中心"视图：悬停中心锚点或任意节点，**动态点亮跨维度关联线**；检索支持 1-3 层多级关联展开（多跳邻居按需点亮，扇出上限防爆）
- 🧠 **两大智能报告** —— 个性培养（M4）与职业方向（M5），按搜索对象自动判定模式
- 🔍 **检索与溯源** —— 全局/跨维度搜索，每个结论可回溯到来源文件与页号；溯源面板一键打开 PDF/网页原件并**直接跳转到被引用的页码**
- 👤 **账号体系与我的画像** —— 加盐哈希登录、个人技能档案点亮、个性培养布局编辑器
- 🛠️ **周边智能工具** —— 课程/竞赛/技能/岗位条目智能解读、政策要点检索、推免加分参考
- ⚙️ **一键启动** —— venv 自检失效自动重建、依赖安装、端口清理、服务探活全自动

## 🧭 四大图谱维度

| 维度 | 内容 |
| --- | --- |
| **专业岗位** | 本专业常见岗位（岗位类别、需求企业、城市、薪资水位） |
| **技能结构** | 岗位技能要求与分类分级（核心技能、等级要求、认证证书） |
| **课程体系** | 专业课程培养与技能对接（开课学年/学期、培养技能、学分） |
| **竞赛实践** | 竞赛锻炼技能与面向专业（级别、时间节点、面向专业） |

图谱支持节点/边的可视化增删改、多工作区管理、全局图谱自动合并去重。底层沿用六表数据契约（发展路径、岗位竞合数据继续入库），作为智能报告的数据底座。

## 🤖 多智能体协同

| 角色 | 职责 |
| --- | --- |
| 抽取引擎 | 按文档类型模板抽取六表结构化数据 |
| JSON 修复器 | 修复大模型输出的非法 JSON |
| 文本校对器 | 删除图谱外实体的表述，防止幻觉入图 |
| 维度分析框架 | 四大维度的图谱分析与统计 |
| M4 / M5 报告专家 | 个性培养 / 职业方向两大报告生成 |
| 总览 / 路径 / 学年规划 | 就业总览、路径规划、分学期学年规划 |

内置职业标准类 / 培养方案类 / 政策·行业报告类 / 竞赛认证类 / 自动识别共 **5 套抽取模板**，按"宁空勿滥"原则禁止从不含该维度的文档强行抽取。

## 📋 两大智能报告

智能分析收敛为两种报告模式，按搜索对象**自动判定**：搜岗位 → 职业方向；搜专业/技能 → 个性培养。

### 个性培养报告（M4）—— "我这个专业四年怎么走"

- 核心交付：**个性化培养思维导图**，五大分支固定：大类通识课 / 专业必修课 / 专业选修课 / 选修课 / 竞赛实践
- 课程按节点属性"开课学年 / 开课学期"逐字归位到"大一~大四 · 秋春学期"时间轴，禁止猜测学期
- 叠加目标岗位时，专业选修课分支给出"★建议优先"标记与一句话选课策略
- 同时输出四段式培养路径报告：目标画像 → 四年培养路径 → 行动清单 → 差距补齐

### 职业方向报告（M5）—— "毕业时我能走哪几条路"

- 核心交付：**职业方向路径图**，5-8 条路径覆盖就业（不同岗位）、考研、直博、升学读研、选调、支教保研、干部保研等类型
- 每条路径：适配度概述 + "专业 → 课程/技能/竞赛 → 目标"发散导图节点 + 分学期行动步骤 + 专属建议
- 就业路径全部落到图谱中真实的课程/技能/竞赛节点并标注来源
- 点击具体岗位，右侧工具栏联动展示**九段式职业发展图**，配合岗位分类总览总览就业面

### 分层接地规则

| 层级 | 约束 |
| --- | --- |
| 权威层 / 多源抽取层 | 事实条目逐条强制标注 `[来源：数据来源名 页号]` |
| AI 建议层 | 开放生成，但禁止编造具体企业名与薪资数字（统一"行业头部企业"表述） |
| 渲染层 | 三级来源分级展示，绝不混排 |

## 🚀 快速开始

### 环境要求

- Windows 10/11
- [Python 3.10+](https://www.python.org/downloads/)（安装时勾选 **Add python.exe to PATH**）

### 配置 API Key

本系统调用天津大学校内词元服务（参赛者报名后自动分配专属 API Key，可在[智能体广场](https://ai.tju.edu.cn/)左下角查看）。按照大赛合规要求，**Key 不写入代码与 Git 仓库**，两种配置方式任选其一：

- 在项目根目录新建 `api_key.txt`，将 Key 粘贴进去（已被 `.gitignore` 排除，不会被提交）
- 或设置环境变量 `TUJU_API_KEY`

> 未配置 Key 时服务仍可启动，图谱浏览等基础功能不受影响，仅调用大模型的功能（材料抽取、智能报告、智能解读）不可用。

### 一键启动

```bat
双击 一键启动.bat
```

脚本会自动完成：

1. 清理残留服务进程与 6006 端口
2. **venv 自检**——venv 不可跨机器/跨路径移植（`pyvenv.cfg` 硬编码创建时的解释器绝对路径），脚本检测到失效 venv 会自动删除重建
3. 通过清华镜像安装依赖
4. 启动服务，探活成功后自动打开浏览器

> 无论是拷贝整个文件夹到别的电脑，还是把项目移动到其它路径，都只需重新双击 `一键启动.bat`，无需手动删 venv。

### 手动启动

```bash
pip install -r requirements.txt
python app.py
```

访问 <http://127.0.0.1:6006>。

### 可选：启用图片 OCR 通道

通道 C（图片 OCR）依赖 RapidOCR，因体积较大未随默认依赖安装，其余功能不受影响：

```bash
venv\Scripts\python.exe -m pip install rapidocr_onnxruntime -i https://pypi.tuna.tsinghua.edu.cn/simple
```
